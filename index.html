Experiment Rules

  • Models only receive information available before the target round.
  • Prediction accuracy measures whether the predicted bot move was correct.
  • Recommendation win rate measures whether the recommended counter actually won.
  • Pattern strength is reduced when sample size is low.
  • The Feature ML model is a lightweight browser-side Naive-Bayes-style classifier, not an LLM.
